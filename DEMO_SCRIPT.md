# AIONOS Assignment 1 — Demo Video Script
Target length: 2–3 minutes

## 0:00–0:20 — Introduction
"Hello, this is my Executive Productivity Agent for AIONOS Assignment 1.
The agent is designed for Arjun Malhotra, VP Sales, and converts emails, calendar entries, a meeting transcript and voice notes into a daily action brief."

## 0:20–0:50 — Daily Action Brief
"On the dashboard, the agent separates the executive's actions from other information.
The first critical item is the Mumbai office lease renewal. Its owner is unclear, so the agent explicitly marks it as unassigned instead of guessing.
The updated vendor list is also pending for Raghav."

## 0:50–1:15 — My Actions
"Here are Arjun's own actions. The vendor list, campaign deck review, expense report review and Meridian call are represented as commitments.
The source field shows where each item came from."

## 1:15–1:35 — Deduplication
"The vendor list is mentioned in the leadership meeting, the email thread and Arjun's voice note. Instead of creating three tasks, the agent normalizes them into one canonical action: Send updated vendor list to Raghav."

## 1:35–1:55 — Waiting and Ownership
"The Waiting on Others section tracks items involving Neha, Divya and Priya.
The Unclear Ownership section is especially important: the Mumbai lease is still unowned in the source data, so the agent does not invent a responsible person."

## 1:55–2:30 — Ask the Agent
"Now I will ask: What did I promise Raghav?"
"The agent identifies the vendor list commitment and explains its latest pending state."

"Next: What needs action today?"
"It returns the lease renewal, vendor list, expense review and today's Meridian call."

## 2:30–2:45 — Close
"The prototype is intentionally lightweight and can run locally from GitHub with one Streamlit command. It uses only the assignment data pack and includes source grounding for traceability."
